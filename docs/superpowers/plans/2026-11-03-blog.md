# Blog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `/blog/` and `/blog/deni/` as prerendered pages joined to the home by view transitions, with the Deni post drawn in Deni's own "Foil and sky" world.

**Architecture:** Vite multi-page build; each blog page is its own HTML entry and React root, prerendered by the existing SSR step and hydrated in the browser. The home stays one page; it only gains the Blog nav link, two "Read the story" buttons and the transition CSS.

**Tech Stack:** React 19, Vite 7, framer-motion (nav lens only), lucide-react, plain CSS with the site's OKLCH tokens.

**Spec:** `docs/superpowers/specs/2026-11-03-blog-design.md`

## Global Constraints

- URLs: `/blog/` and `/blog/deni/`, always with the trailing slash.
- Nav order: Work, About, Blog, Contact. Phone tab bar: Home, Work, About, Blog, Contact.
- Deni tokens: pearl `#F3F5FA`, night ink `#0D1124`, ink `#141B2D`, ink-2 `#4A5164`, blue `#2F6BF2`, link blue `#1C44AE` (light) / `#9DB7FF` (dark), rose `#E8445A`.
- Deni hours: morning 5–12, afternoon 12–17, evening 17–22, night 22–5.
- Text contrast ≥7:1 for body text, ≥4.5:1 at 24px+, in both themes.
- No render-time reads of `window`, `document` or `localStorage` (prerender runs in Node).
- Every animation has a `prefers-reduced-motion: reduce` path.
- Copy states only facts from Carl's LinkedIn caption, the meditrack specs, listing and git history.
- No new dependencies.
- Portfolio commits carry no Co-Authored-By trailer; commit only when Carl asks.

## Review Focus

- A visitor with the dark theme saved lands on a blog page: no flash of light theme and no hydration error (Task 2 checks the console on a dark reload).
- Switching the theme on the home or a blog page still plays the circular reveal, not a cross-fade of the nav (Task 2 step).
- Navigating from a blog page to `/#work` lands on Work after the boot loader, not at the top (Task 5 step).
- A phone at 375px: the five-tab bar, the chapter strip and the hero all fit without horizontal scroll (Task 6 step).
- Blog pages don't download the home's `ui`, `gpu` or `gsap` chunks (Task 1 build check).
