How to build it: three ways, one pick
Pick

Real pages + view transitions

Vite builds /blog and /blog/deni as their own pages, prerendered like the home.
  • A real link to share on LinkedIn, with its own preview card
  • Google and AI crawlers read every post in full
  • The home’s code doesn’t change, so its 94 speed score holds
  • A post loads light: no WebGPU field, no boot loader
  • Pages morph into each other in Chrome, Edge and Safari 18.2+
  • Firefox gets a normal (fast) page load instead of the morph

Change screens in the page

The post opens as a full-screen layer over the home.
  • Instant, and the morph works everywhere
  • No link to a post: you can’t share it or bookmark it
  • The Back button leaves the whole site
  • Crawlers never see the posts
  • Every post’s code ships with the home

A router inside the app

One React app switches between routes.
  • Seamless in every browser, real URLs
  • Someone landing on a post from LinkedIn waits for the home’s boot
  • Puts a router into App.jsx, which owns the perf work
  • Going back home re-runs the hero field from scratch

Back to the home: the browser’s Back button restores the home from memory, instantly. A clicked link home skips the boot loader’s hold when you arrive from a blog page, since the files are already cached.

03 · The move between pages

The phone and its sky fly into the post. The nav holds still.

Cross-document view transitions: the browser snapshots both pages and morphs the pieces that share a name. About half a second, eased, never springy, which is Deni’s own motion rule. With reduced motion it’s a plain cross-fade. Back plays it in reverse.

Shared names: site-nav (holds still), deni-sky, deni-phone. From /blog, the post’s cover carries the same names, so the index morphs into the post the same way.

03 · Evening

Everything stays on the phone

The real app keeps everything on the iPhone, in SQLite. It stores only facts, like “a dose was taken at 8:02,” and works out the rest with small pure functions: what’s late, what’s missed, how many pills are left.

Rules I wrote down before any screen
A dose is Late until midnight, then Missed.
Skipping isn’t missing, and it uses no supply.
Deleting a med stops it. Its history stays.

06 · What stays Carl’s, what becomes the post’s

A fixed frame, and a world each post brings inside it.

The rule that keeps it one site: the frame never changes, so you always know where you are. Inside the frame, the post’s project is the designer. Mint stays the site’s; Deni blue is Deni’s.

The frame · same on every post
  • The nav pill, tab bar, theme toggle and their mint lens
  • One type family (SF Pro on Apple devices, Inter elsewhere), same scale
  • A 64-character reading column, 20 px text, 1.65 leading
  • Title, date, reading time, “All posts,” “More from the blog”
  • AAA contrast for every line of text, in both themes
  • Reduced motion turns every move into a cross-fade
